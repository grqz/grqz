# Getting started with Microsoft 365

Microsoft 365 combines Office applications, cloud storage, collaboration tools,
and identity management under one subscription. This guide outlines a safe,
practical first setup for a new tenant or personal account.

## 1. Choose the right account

- Use a **personal Microsoft account** for consumer subscriptions such as
  Microsoft 365 Personal or Family.
- Use a **work or school account** for an organization-managed subscription.
  An administrator creates these accounts and controls access to services,
  billing, and security settings.

Do not share an account between people. Each person should have their own
identity so permissions, files, and audit history remain attributable.

## 2. Sign in and verify the subscription

Sign in through the official Microsoft 365 portal:

<https://www.microsoft365.com/>

Confirm that the expected apps and storage are available. Organizations can
review licenses and users in the Microsoft 365 admin center:

<https://admin.microsoft.com/>

Only assign the services each user needs. Removing unused licenses reduces
costs and limits unnecessary access.

## 3. Set up security first

1. Enable multifactor authentication (MFA). Prefer an authenticator app or
   passkey over SMS where supported.
2. Add recovery methods and store backup codes somewhere secure.
3. Use a unique password and never approve an unexpected sign-in prompt.
4. Administrators should create at least two emergency admin accounts,
   protect them with strong authentication, and monitor their use.
5. Review sign-in activity regularly and revoke sessions or devices that are
   no longer trusted.

Microsoft's security guidance is available at
<https://learn.microsoft.com/en-us/microsoft-365/security/>.

## 4. Install the apps and connect devices

Install only from the Microsoft 365 portal or official app stores. Sign in
with the account that owns the license, then keep Windows, macOS, iOS, Android,
and Office applications updated.

Before enabling synchronization on a shared or unmanaged device, verify that
the device is encrypted and protected by a screen lock. Avoid syncing
confidential work files to personal devices unless your organization allows it.

## 5. Organize files and collaboration

- Store personal work in **OneDrive**.
- Store team-owned work in **SharePoint** or the appropriate **Teams** channel.
- Use descriptive names and consistent folders.
- Share links with the narrowest audience and shortest practical expiration.
- Prefer “can view” over “can edit” when editing is not required.

Sharing a link is not the same as making a backup. Keep a recovery plan and
review deleted-file retention and version history for important content.

## 6. Learn the core apps

- **Outlook**: email, calendar, and contacts.
- **Teams**: chat, meetings, and team collaboration.
- **Word, Excel, and PowerPoint**: document, spreadsheet, and presentation
  creation.
- **OneDrive**: individual file storage and synchronization.
- **SharePoint**: shared sites, document libraries, and intranet content.
- **OneNote**: notes and shared notebooks.

Start with a small test document and a test meeting before migrating
important data or inviting a large group.

## 7. Get help safely

Use Microsoft's official support and documentation:

- <https://support.microsoft.com/microsoft-365>
- <https://learn.microsoft.com/microsoft-365/>

Be cautious of unsolicited “Microsoft support” calls, emails, and remote-access
requests. Microsoft support will not ask for your password or MFA approval.
